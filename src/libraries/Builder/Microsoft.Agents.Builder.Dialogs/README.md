# Microsoft.Agents.Builder.Dialogs

## About

Provides multi-turn dialog support for agents built with the Microsoft 365 Agents SDK, including
waterfall dialogs, prompts, and reusable component dialogs. Supports reuse of existing Bot Framework
SDK dialogs.
