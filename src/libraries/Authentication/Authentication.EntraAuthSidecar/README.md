# Microsoft.Agents.Authentication.EntraAuthSidecar

## About

Provides token acquisition through the Microsoft Entra ID Agent Container sidecar for agents built
with the Microsoft 365 Agents SDK. Supports connection and agentic identity tokens while keeping
credential management outside the agent process.
