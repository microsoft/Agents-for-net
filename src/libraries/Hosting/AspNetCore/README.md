# Microsoft.Agents.Hosting.AspNetCore

## About

Provides ASP.NET Core hosting for agents built with the Microsoft 365 Agents SDK. Integrates agent
services and adapters with dependency injection, middleware, HTTP endpoint routing, and
application-defined authentication and authorization.
