# Microsoft.Agents.Hosting.DirectLine.NamedPipes

## About

Provides named-pipe transport for agents built with the Microsoft 365 Agents SDK. Enables
communication with the Direct Line App Service extension (DirectLineFlex) in Azure App Service
without HTTP roundtrips.
