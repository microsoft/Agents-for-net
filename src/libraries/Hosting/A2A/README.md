# Microsoft.Agents.Hosting.A2A

## About

Legacy preview hosting integration for the Agent2Agent (A2A) protocol in the Microsoft 365 Agents
SDK. Current A2A support is provided by Microsoft.Agents.Extensions.A2A.Preview.
